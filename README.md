<h1 align="center">ระบบปรับลดราคา BOQ ตาม ว 651</h1>

<p align="center">
  คำนวณการปรับลดราคาในแบบแสดงรายการ ปริมาณงาน และราคา (BOQ)<br>

  ระบบออกรายงานแบบสรุปราคากลางและเอกสารแนบท้ายสัญญาจ้างก่อสร้างได้ในตัว

## ใช้งานได้ 2 แบบ

| | แอปติดตั้งในเครื่อง (PWA) | เว็บแอป Google Apps Script |
|---|---|---|
| วิธีเปิด | ติดตั้งจากหน้า GitHub Pages ลงคอมพิวเตอร์ แท็บเล็ต หรือมือถือ | เปิดจาก URL ของ Web App |
| ข้อมูลเก็บที่ | เบราว์เซอร์ในเครื่องนั้น (สำรองหรือย้ายได้ด้วยไฟล์ .json) | Google Sheets ใช้ร่วมกันได้ทั้งสำนักงาน |
| อินเทอร์เน็ต | ไม่ต้องใช้ หลังติดตั้งแล้ว | ต้องใช้ |
| พิมพ์ / PDF | ได้ (A4 แนวนอนและแนวตั้ง) | ได้ ส่งออก Google Sheets และสร้าง PDF เก็บใน Drive ได้ด้วย |
| เหมาะกับ | ใช้คนเดียว ทำงานนอกสถานที่ หรือทดลองใช้ | ใช้หลายคนร่วมกัน และต้องการเก็บข้อมูลไว้ส่วนกลาง |

สองแบบนี้ใช้สูตรคำนวณชุดเดียวกัน คือ `lib/engine.js` และหน้าจอชุดเดียวกัน คือ `apps-script/*.html`

## ความสามารถ

- กรอกข้อมูลโครงการ หมวดงาน และค่า Factor F
  - มีตัวเลือกราคากลางบวกเพิ่ม 5% สำหรับงานใน 3 จังหวัดชายแดนภาคใต้
- กรอก BOQ โดยแบ่งหัวข้อ / หัวข้อย่อย และมีบรรทัดรวม หรือ **วางจาก Excel** ได้ทันที
- คำนวณ (1)(2)(3) และอัตราร้อยละตามแบบสรุปราคากลาง
  - ไม่ปรับลดค่าใช้จ่ายพิเศษตามข้อกำหนด
  - ปรับส่วนต่างจากการปัดเศษให้วงเงินรวมเท่ากับราคาตามคำเสนอพอดี
- วิเคราะห์กรณีตาม **ข้อ 1.2.2–1.2.4** และตรวจเงื่อนไขการใช้บังคับตาม **ข้อ 2**
- รายงานตามสิ่งที่ส่งมาด้วย
  - **แบบที่ 1** แบบสรุปราคากลาง
  - **แบบที่ 2** แบบแสดงรายการ ปริมาณงาน และราคา (เอกสารแนบท้ายสัญญา) มีจำนวนเงินเป็นตัวอักษรไทยและช่องลงนาม
- มีหน้าสรุปข้อกฎหมาย ผังการพิจารณา และคู่มือการใช้งาน

## ผลทดสอบเทียบกับตัวอย่างในหนังสือ

| ตัวอย่าง | ร้อยละ | ผล |
|---|---|---|
| 1 งานอาคาร | 1.57 | ตรงทุกรายการถึงหลักสตางค์ |
| 2 งานอาคาร 3 จชต. (+5%) | 6.46 | ตรงทุกรายการถึงหลักสตางค์ |
| 3 งานทาง สะพาน และท่อเหลี่ยม | 9.39 | ตรงทุกรายการถึงหลักสตางค์ |
| 4 งานชลประทาน | 4.20 | วงเงินรวมตรงกัน มี 4 รายการต่างกัน ±0.01 บาท (ตัวอย่างนี้ปัดเศษไม่สม่ำเสมอ) |

รันทดสอบเองได้ด้วยคำสั่ง `npm test` ระบบ GitHub Actions จะรันชุดทดสอบนี้ทุกครั้งที่ push

> วิธีปัดเศษ ได้แก่ ตัดทศนิยมร้อยละ 2 ตำแหน่ง ตัดเศษสตางค์ และปรับส่วนต่างเข้ารายการที่ราคาสูงสุด **อนุมานจากตัวเลขในตัวอย่าง** เพราะหนังสือไม่ได้เขียนไว้เป็นข้อความ ในระบบเปลี่ยนวิธีปัดเศษได้

### วิธีคำนวณ (เลือกได้ในหน้าผลการปรับลดราคา)

ทุกวิธียึดหลักตามหนังสือ: ปรับราคาทุกรายการเทียบกับราคากลาง (ข้อ 1.2.2) ไม่ปรับค่าใช้จ่ายพิเศษ และวงเงินรวมต้องเท่ากับราคาตามคำเสนอ

| | ตามหลักหนังสือ ว 651 (ค่าเริ่มต้น) | ตามตัวอย่างทุกประการ | ทางเลือก: กระจายเศษ |
|---|---|---|---|
| อัตราที่ใช้ลด | ร้อยละตามแบบสรุปราคากลาง (ตัด 2 ตำแหน่ง) | ร้อยละตามแบบสรุปราคากลาง (ตัด 2 ตำแหน่ง) | สัดส่วนจริง (2) ÷ (1) |
| คูณที่ | ราคาต่อหน่วย แล้ว ราคา = จำนวน × ราคาต่อหน่วย | ราคารวมรายการ แล้ว ราคาต่อหน่วย = ราคา ÷ จำนวน | ราคาต่อหน่วย |
| ส่วนต่าง (*) | รายการเดียว (ราคาสูงสุดที่ไม่มีรายการซ้ำ หรือเลือกเอง) | รายการเดียว | หลายรายการ ทีละ 1 สตางค์ |
| รายการที่กรอกเหมือนกัน | ได้ราคาเท่ากัน | อาจไม่เท่ากัน | ได้ราคาเท่ากัน |
| ตรงกับตัวอย่างในหนังสือ | หลักการตรง ตัวเลขต่างได้ไม่กี่บาท | ตรงทุกสตางค์ | หลักการต่าง |

กรอก "ราคากลางที่ประกาศ" ในข้อมูลโครงการ เพื่อให้ระบบตรวจว่าราคากลางที่คำนวณตรงกับที่ประกาศ

## 1) อัปโหลดขึ้น GitHub

**วิธีที่ 1: ผ่านหน้าเว็บ (ไม่ต้องใช้คำสั่ง)**
1. ไปที่ github.com แล้วกด **New repository** ตั้งชื่อ `w651` เลือก **Public** แล้วกด Create
2. กด **uploading an existing file** แล้วลากไฟล์และโฟลเดอร์ทั้งหมดในโปรเจกต์นี้ลงไป (รวมโฟลเดอร์ `.github`)
3. กด **Commit changes**

> ถ้าลากโฟลเดอร์ `.github` ไม่ขึ้น (บางเบราว์เซอร์ซ่อนโฟลเดอร์ที่ขึ้นต้นด้วยจุด) ให้กด **Add file → Create new file** แล้วพิมพ์ชื่อ `.github/workflows/pages.yml` จากนั้นวางเนื้อหาจากไฟล์นั้นลงไป

**วิธีที่ 2: ใช้ git**
```bash
git init
git add .
git commit -m "ระบบปรับลดราคา BOQ ตาม ว 651"
git branch -M main
git remote add origin https://github.com/THARATEP/w651.git
git push -u origin main
```

## 2) เปิดหน้าเว็บสำหรับติดตั้ง (GitHub Pages)

1. ใน repository ไปที่ **Settings → Pages**
2. ที่หัวข้อ **Build and deployment → Source** ให้เลือก **GitHub Actions**
3. ไปที่แท็บ **Actions** แล้วรอให้ขั้นตอน *Test & Deploy PWA* ขึ้นเครื่องหมายถูกสีเขียว (ประมาณ 1 นาที)
4. แอปจะอยู่ที่ `https://tharatep.github.io/w651/`

## 3) ติดตั้งลงเครื่อง

| อุปกรณ์ | วิธีติดตั้ง |
|---|---|
| **Windows / macOS** (Chrome, Edge) | เปิดลิงก์แอป แล้วกดปุ่ม **ติดตั้งแอป** ที่มุมขวาบน หรือกดไอคอน ⊕ ในช่อง URL จากนั้นแอปจะอยู่ในเมนู Start / Launchpad และปักหมุดที่ Taskbar ได้ |
| **Android** (Chrome) | เปิดลิงก์แล้วกด **ติดตั้งแอป** หรือเมนู ⋮ → **ติดตั้งแอป** / **เพิ่มลงในหน้าจอหลัก** |
| **iPhone / iPad** (Safari) | เปิดลิงก์ใน Safari กดปุ่ม **แชร์** แล้วเลือก **เพิ่มไปยังหน้าจอโฮม** |

หลังติดตั้งแล้ว แอปใช้งานแบบออฟไลน์ได้ เมื่อมีการ push เวอร์ชันใหม่ แอปจะแสดงปุ่ม **อัปเดตเลย** ให้เอง

**ข้อมูลในโหมดติดตั้ง** จะเก็บอยู่ในเครื่องนั้นเท่านั้น
- ควรกด **ตั้งค่า → สำรองข้อมูล (.json)** เป็นระยะ
- ใช้ **นำเข้าข้อมูลสำรอง** เพื่อย้ายข้อมูลไปเครื่องอื่น

## 4) ติดตั้งแบบ Google Apps Script (ใช้ร่วมกันทั้งสำนักงาน)

**วิธีที่ 1: คัดลอกและวาง**
1. สร้าง Google Sheets ใหม่ แล้วไปที่เมนู **ส่วนขยาย → Apps Script**
2. สร้างไฟล์ให้ตรงกับชื่อในโฟลเดอร์ `apps-script/` โดยไม่ต้องพิมพ์นามสกุล
   - ชนิด **สคริปต์**: `Code`, `Engine`
   - ชนิด **HTML**: `Index`, `Css`, `App`, `EngineJs`, `Samples`, `Law`
3. เปิด **⚙ การตั้งค่าโปรเจ็กต์** แล้วติ๊ก *แสดงไฟล์ "appsscript.json"* จากนั้นวางเนื้อหาไฟล์นั้นลงไป
4. เลือกฟังก์ชัน `setup` กด **เรียกใช้** แล้วกดอนุญาตสิทธิ์
5. กด **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: เลือกตามที่หน่วยงานกำหนด
6. (ไม่บังคับ) แก้ `ICON_URL` ในไฟล์ `Code.gs` เป็น
   `https://cdn.jsdelivr.net/gh/THARATEP/w651@main/web/icons/icon-64.png`
   เพื่อให้แท็บเบราว์เซอร์แสดงไอคอนของแอป

**วิธีที่ 2: ใช้ clasp (สำหรับนักพัฒนา)**
```bash
npx @google/clasp login
cp .clasp.json.example .clasp.json   # แล้วใส่ scriptId ของโปรเจกต์
npm run push                          # build แล้วอัปโหลดไฟล์ใน apps-script/
npm run deploy                        # สร้างเวอร์ชันใหม่ของ Web App
```

## สำหรับนักพัฒนา

```
├─ lib/engine.js          สูตรคำนวณ (ต้นฉบับเดียว ใช้ทั้งฝั่ง Apps Script และ PWA)
├─ apps-script/           ต้นฉบับหน้าจอและฝั่งเซิร์ฟเวอร์ (clasp rootDir)
│   ├─ Code.gs            API / Google Sheets / ส่งออก Sheets และ PDF
│   ├─ Index·Css·App      หน้าจอ
│   ├─ Samples·Law        ข้อมูลตัวอย่าง ว 651 และหน้าข้อกฎหมาย
│   └─ Engine.gs, EngineJs.html   ← สร้างจาก lib/engine.js
├─ web/                   PWA ที่เผยแพร่บน GitHub Pages
│   ├─ index.html, sw.js  ← สร้างโดย tools/build.mjs
│   ├─ manifest.json, icons/, fonts/, vendor/
├─ tools/build.mjs        สคริปต์ build (Node 18+ ไม่ต้องติดตั้งแพ็กเกจเพิ่ม)
└─ tests/engine.test.mjs  ทดสอบกับตัวอย่างในหนังสือ ว 651
```

```bash
npm run build    # สร้าง Engine.gs, EngineJs.html, web/index.html, web/sw.js
npm test         # ทดสอบสูตรคำนวณ
npm run serve    # เปิดทดสอบ PWA ที่ http://localhost:8080
```

แก้ไขเฉพาะ `lib/` และ `apps-script/` (ยกเว้นไฟล์ที่ระบบสร้างให้) แล้วรัน `npm run build` ก่อน commit ทุกครั้ง
